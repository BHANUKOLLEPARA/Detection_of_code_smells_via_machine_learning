# Detection of Code Smells using Machine Learning

## Project Overview
This project is a web-based application developed using Python and Django to automatically detect code smells using software metrics and Machine Learning techniques. It helps developers identify poor coding practices and improve software quality.

## Features
- Upload source code files
- Extract software metrics
- Detect code smells using Machine Learning
- Generate analysis reports
- User-friendly web interface

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning (Scikit-learn)

## Project Structure
- accounts/
- core/
- detector/
- static/
- templates/
- manage.py

## How to Run
1. Clone the repository.
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the server:
   ```
   python manage.py runserver
   ```
4. Open the application in your browser.
